# Keel can show it makes projects better, or find out that it does not

## Done when

A dated research page compares the fleet before and after adoption on measures fixed in advance (red-streak length, time from lesson to guard, phases moved per week, conduct cost per phase) and says plainly what it found.

## Scope

Fix the measures and the comparison before looking. Golden tasks for keel
itself: init a project of each kind, adopt a fixture, carry a migration —
each with machine-checkable outcomes, run with and without keel's skills
(isocan's skill-lift method).

## Acceptance

- [ ] Measures and comparison written down, dated, before the data is read.
- [ ] The page reports a null or negative result as plainly as a positive one.

## Proof

The research page, its numbers reproducible from the commands it names.

## Deliberately open

- How long a fleet must run before the comparison means anything. Decide when writing the measures, not after seeing them.
