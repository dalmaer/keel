## Gaps and decision

- Stalls about once a second slow both sides of a ratio in proportion, so the climb compare tests, which judge a 30% margin between two wall times, were never named, at 1500 ms or at 600 ms. What failed CI was node's start-up cost on a busy runner, which stalls do not model. The tests moved to the suite's own clock because they judge the wall clock by construction, not because stalls named them.
- The gate's time after is not measured here: this machine was under other builders' load all session. climb.test.mjs no longer sleeps (about 30 s of real waits gone), but it was never alone as the longest file, and the six pinned files now also run with stalls beside the suite. The owner's walk reads both from the ledger on main.
- Linux (the gate on GitHub Actions) is not run here.
- Supports partial, owes the ⚑ walk.
