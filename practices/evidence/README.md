# evidence

**The failure it prevents.** "Built" claimed from a plan, or a scripted run
reported as a person's use. A claim nobody can check is believed anyway.

**The rule.** `built` and `lived-in` need an evidence file under
`docs/evidence/` saying what was run, with exit codes, and what was not.
Never write expectations as observations.

**Its files.** `docs/templates/evidence.md` (managed); the `evidence` block of
`AGENTS.md`.

**Lineage.** ledger's evidence notes, made mandatory by ritmo's roadmap check.
